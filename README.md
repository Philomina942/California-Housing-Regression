# California Housing Regression

## 📌 Project Overview
This project demonstrates the implementation and comparison of multiple regression algorithms using the California Housing dataset from the Scikit-learn library. The objective is to predict median house prices and evaluate the performance of different regression models.

## 📂 Dataset
- **Dataset:** California Housing Dataset
- **Source:** `sklearn.datasets.fetch_california_housing()`

## 🛠️ Regression Models Implemented
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- Support Vector Regressor (SVR)

## 📊 Evaluation Metrics
The models were evaluated using:
- Mean Squared Error (MSE)
- Mean Absolute Error (MAE)
- R² Score

## 🏆 Result
The performance of all regression models was compared, and the **Random Forest Regressor** achieved the best performance based on the evaluation metrics.
